# Awaken Turiya — Psychic Intuition Trainer (web build)

The browser build of the Awaken Turiya app, published with GitHub Pages and
embedded on [awakenturiya.com](https://awakenturiya.com).

Live: https://blindfoldedsight-code.github.io/awaken-turiya-app/

Five training modes (black or white, suits, dice, colors, full deck), 20 rounds
per session, every answer spoken aloud so the app can be used blindfolded.
Optional score tracking: tap the left half for wrong, the right half for right.
On a keyboard, Space reveals and the arrow keys score.

Installs to a home screen and works offline (PWA). No accounts, no analytics,
no data leaves the device — the only thing stored is the score-tracking
preference, in `localStorage`.

Source of record for the app itself is the private `AwakenTuriya` repo
(`docs/app/`); this repo is the public hosting mirror.
